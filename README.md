# CNN-model-stars-and-galaxy-classification-image
## Project Overview

This repository contains one of the solutions aimed at developing effective deep learning models for the classification of star and galaxy images.

**Objective:** Develop an optimized CNN model to classify stars and galaxy images with maximum efficiency and accuracy.

### File Details in this Repository:

- **`Cnn.ipynb`** - Main Jupyter notebook containing:
  - Complete data preprocessing pipeline
  - CNN model architecture and training code
  - Evaluation and visualization
  - Optimization techniques

- **`Cnn-class-image.h5`** - Pre-trained optimized model:
  -  0.8667 % validation accuracy
  - Only 0.233 MB file size

## Dataset Information

### Original Dataset
- **Source Galaxy:** [Galaxy](https://drive.google.com/drive/folders/1Fy_d9zwyvXdjXsSU99e2G7o_BAyjZwlj)
- **Source stars:** [stars](https://drive.google.com/drive/folders/1MIBWujpWGoBl-M6nLl0GeptBt4SSaLSv)
- **Size:** 44,947 images total
- **Dimensions:** 32×32x3
- **Format:** NumPy arrays (.npy files)
